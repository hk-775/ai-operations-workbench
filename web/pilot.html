Know what your tasks cost.

How to read these costs

What is included in the estimate?

Token counts reported by the provider are multiplied by the saved model prices. Calls with missing usage or unsupported prices remain unknown. A known subtotal can therefore be lower than the full cost.

Hardware and electricity are unmeasured. Billing reconciliation compares imported charges with declared captured scopes separately; individual task invoice costs remain unknown. Calls captured only at the final response may omit retries and failed attempts. Synthetic test data is excluded unless you select it above.

USAGE SOURCES

Connect the application you want to understand.

A source identifies where usage comes from, such as your support application. Each application gets its own connection token and call history.

Choose how to bring usage into Workbench.

Explore first: load the saved comparison in Model evaluations. It appears here as a recorded source.

Connect an application: choose AxonLLM or Amazon Bedrock, create a source and connection token, then add its capture wrapper to your application and run the delivery process.

Creating a source alone does not start collecting calls. Prompt text and model responses stay out of the usage ledger. Choose one capture wrapper per call to avoid counting the same call in two sources.

Amazon Bedrock setup and coverage
  1. Create an Amazon Bedrock source below and save its token in a private file on your application host.
  2. Use capture_converse or capture_converse_stream from workbench.bedrock around your existing boto3 calls. Group related calls with the same task ID.
  3. Set WORKBENCH_INGEST_URL to this workspace’s /api/pilot/ingest URL, and WORKBENCH_INGEST_TOKEN_FILE to the private token file.
  4. Run uv run --locked python -m workbench.connector --outbox .pilot/bedrock.outbox.db deliver --watch on the application host, using the same outbox as capture.

Install the optional SDK with uv sync --locked --extra bedrock. Full examples and recovery instructions are in docs/BEDROCK.md in the source download.

Captures instrumented Converse and ConverseStream calls only. It does not import AWS account history or invoices. Token usage is separate from output quality. The initial reviewed rate covers uncached Nova Micro in us-east-1 at standard on-demand pricing; unsupported prices stay unknown.

Connected means the delivery process reported within three minutes. It does not prove that every application call is instrumented. Queue counts are the last report; a stale report can hide a growing backlog.

Save this ingestion token

Shown once. Store it in a private token file on the application host. It expires in 30 days; rotate before expiry.

Developer connection instructions

Use Workbench’s capture_completion adapter to save call metadata to a durable outbox. A separate delivery process sends it with the connection token. Retrying delivery of the same event does not count it twice.
