# Support

Use GitHub issues for reproducible bugs and feature requests. Before filing,
check the [quickstart](README.md), [methodology](docs/METHODOLOGY.md), and
[roadmap](docs/ROADMAP.md).

Include the release or commit, operating system, Python and browser versions,
the command or screen involved, and a redacted error. Prefer the bundled
recording or a minimal fictional example.

This is a community project without a response-time guarantee or commercial
support commitment. It does not currently provide native Codex, Cursor,
Claude Code, or Bedrock billing connectors.

Report vulnerabilities through [SECURITY.md](SECURITY.md), not public issues.
